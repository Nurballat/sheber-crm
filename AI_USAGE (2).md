## My 3 most useful prompts

1. I uploaded the SIS3 assignment PDF and wrote: "now we need to do this assignment, our project is the one you made for me for the first SIS". This produced the plan with three screens (list, details, add request).
2. I uploaded the mockup and wrote: "let's compare the interface template and the design we want to repeat with what we got, let's finish everything and make it as similar as possible". After this the screens got section icons, status badges, dropdowns and a camera counter.
3. I pasted the output of `git status` after the commit command. Claude noticed that the commit also contained the deletion of `Color.kt` and `Theme.kt`, and told me to undo it with `git reset HEAD~1` and commit again.

## Cases where the AI was wrong

**Deprecated `menuAnchor()`.** In `AddLeadScreen.kt`, Claude wrote `Modifier.menuAnchor()` without parameters. The code compiled, but Android Studio showed the warning `'fun Modifier.menuAnchor(): Modifier' is deprecated`. I noticed it in the Build tab and pasted the text into the chat. The fix: `menuAnchor(MenuAnchorType.PrimaryNotEditable)`, because the field is `readOnly` and only opens the list.

**Hardcoded color.** In the first version of `StatusChip.kt`, Claude wrote `Color.White` directly in the component. This breaks the assignment rule that colors may only be defined in the theme. It was found while checking against the checklist. The fix: the `OnStatusChip` color is in `Color.kt` and the component takes it from there.

**Missing imports.** Several files had missing imports (`defaultMinSize`, `fillMaxWidth`) or unused ones (`Box`). These were fixed using Android Studio hints.
